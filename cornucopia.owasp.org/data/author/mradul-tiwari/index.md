# Mradul Tiwari

Mradul Tiwari is a Google Summer of Code 2026 contributor to OWASP Cornucopia and an undergraduate student of Information Technology at IIIT Gwalior, India. He built the project's Scribus-based print pipeline, which turns the card data held in Cornucopia's YAML files into print-ready PDF decks without any proprietary design software, so that a release can produce its own printable cards.

Before GSoC he had already contributed across much of the project, from the API and the SvelteKit website to the CI/CD pipeline and its security scanning, and it was while fixing a problem in the release workflow that he noticed PDF generation was the one step nobody could automate. He is interested in the place where developer tooling meets application security, and intends to keep contributing to Cornucopia and to help new contributors find their way into it.
